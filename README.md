# Цифровой ординатор: СППР и симулятор пациента

Ведение пациента в стационаре по КР Минздрава РФ: RAG-план со ссылками на пункты КР, детерминированная симуляция до 3-х суток с пересмотром тактики, AI-аудитор трека. Данные синтетические, не для клинического применения. Подробности - в [docs/details.md](docs/details.md).

**КР 154_4** «Острый коронарный синдром без подъёма сегмента ST электрокардиограммы» (Минздрав РФ, опубл. 23.10.2024, действует), выбрана из 6 кандидатов: числовые пороги для всех проверок аудитора (рСКФ для антикоагулянтов, контраст/рСКФ < 3,7 и гидратация, ИПП при ДАТТ, НПВП, тромбоциты), 219 тезисов с УУР/УДД, пункты до 4-го уровня.

## Пайплайн

```
КР (API рубрикатора) → parse → 383 чанка (тезис + УУР/УДД + комментарий, строки таблиц доз)
                                      │
Пациент ─► ① Planner: 7 клинических областей × [подзапросы по подтемам, поиск hybrid + фильтр по разделу КР]
             → Qwen3.8-27B (строгий JSON-schema) → проверка ссылок, аллергий, дублей, полноты → план
        ─► ② Simulator (формулы, seed) → контрольная точка 72 ч → Monitor (пороги КР)
             → при отклонениях Replanner (LLM + те же проверки) → отмена/новые назначения
        ─► ③ Auditor: 14 правил с цитатами КР/323-ФЗ + LLM-аудит (Nemotron 3 Ultra) → проверка находок Qwen → отчёт
```

**Почему так**
- **RAG по разметке КР**, без кластеризации и нарезки по длине: ссылка ведёт на пункт (`[КР 154_4, п. 3.2.3.2, тезис 6; УУР A, УДД 2]`). Поиск hybrid (BM25 + `deepvk/USER2-base`, RRF) лучший на 30 запросах: Recall@10 0.961 против 0.861 / 0.850.
- **Цепочка промптов, а не вызов инструментов:** поиск вызывает код по клиническим областям с фильтром раздела КР. Прогон воспроизводим и кэшируется, а бесплатные модели не решают сами, что искать.
- **Против галлюцинаций:** назначение попадает в план, только если `chunk_id` был в контексте, цитата дословно есть в чанке, а препарат и числа дозы есть в цитате. Плюс защиты от аллергенов, дублей и двух P2Y12, проверка полноты по группам, которые КР рекомендует пациенту (АСК, P2Y12, статин, иАПФ/АРА, при ФВ ≤ 40% бета-блокатор и эплеренон), и проверка, что отмена в пересмотре относится к отменяемому назначению.
- **Динамика - формулы, не LLM:** тропонин, креатинин/рСКФ (CKD-EPI 2021, контраст-индуцированное ОПП с учётом гидратации из плана), Hb, K⁺; seed.
- **Аудитор - гибрид:** правила не пропускают очевидное, LLM ищет неформализованное, а модель другого семейства проверяет каждую LLM-находку по тезису и треку; отклонённые показываются отдельно.
- **LLM:** Qwen3.8-27B (Groq) и Nemotron 3 Ultra (OpenRouter), бесплатные, thinking выключен. Mistral отпал: на бесплатном плане 429/403, а `ministral-14b` игнорировала условия тезисов. Сравнение моделей - в [details](docs/details.md#выбор-llm).

## Синтетическая когорта

| Кейс | Паттерн | Что происходит | Заложенные дефекты (внешние назначения) |
|---|---|---|---|
| case1 | Baseline | М 56, ИМбпST, ранняя КГ+ЧКВ, к 72 ч тропонин ↓, почки стабильны | нет (проверка ложных срабатываний) |
| case2 | Comorbid | Ж 76, ХБП С3б, язва с ЖКК, ангиоотёк на иАПФ, ФВ 38%, ХСН | эналаприл, диклофенак; омепразол (дефект только при клопидогреле) |
| case3 | Reactive | М 72, СД 2, рСКФ 48, 260 мл контраста → ОПП: рСКФ 48 → 18 к 72 ч, K⁺ 5,7, пересмотр плана | эноксапарин 1 мг/кг 2 р/сут после ЧКВ; ИДС оформлено после вмешательства; этапное ЧКВ с 200 мл контраста |

## Результаты (ноутбук 02)

| Кейс | Назначений planner, все со ссылкой | Отклонений на 72 ч | Находки crit/major/minor (правила + LLM) | Отклонено проверкой | Заложенные дефекты |
|---|---|---|---|---|---|
| case1 | 16 | 0 | 0/0/0 | 3 | нет, ложных срабатываний нет |
| case2 | 18 | 0 | 2/2/1 (3 + 2) | 1 | 2/2 |
| case3 | 17 | 4 | 1/4/0 (4 + 1) | 2 | 2/2 |

- **case2:** валсартан вместо иАПФ, клопидогрел вместо тикагрелора (76 лет, высокий риск кровотечений), пантопразол, бисопролол и эплеренон (ФВ 38%, ХСН; эплеренон добавила проверка полноты).
- **case3, пересмотр на 72 ч:** отменены эноксапарин, этапное ЧКВ, лизиноприл; добавлены гидратация, НФГ, контроль электролитов. Замену эноксапарина на НФГ после успешного ЧКВ поймало правило R13.

## Пример, пойманный аудитором (case3)

Через 6 ч после успешного ЧКВ палатный врач назначил **эноксапарин натрия 80 мг (1 мг/кг) 2 раза в сутки** «для продолжения антикоагулянтной терапии»; из-за контраст-индуцированного ОПП рСКФ 22 к 48 ч, 18 к 72 ч.

- **R13 (major):** антикоагулянт > 24 ч после успешного ЧКВ без показаний. П. 3.2.3.2, тезис 2: «После успешного ЧКВ у пациентов с ОКСбпST рекомендуется прекратить парентеральное введение антикоагулянта из-за опасности увеличения риска кровотечений».
- **R1 (major):** на 48 ч при рСКФ 22,4 доза не скорректирована. П. А3, табл. 4, строка 11: «у пациентов со скоростью клубочковой фильтрации < 30 мл/мин/1,73 м 2 подкожно 1 мг/кг 1 раз в сутки».
- **R3 (critical, процедурная):** согласие на КГ+ЧКВ датировано 15 ч, вмешательство в 14 ч (323-ФЗ, ст. 20).

## Запуск

```bash
python -m venv .venv && source .venv/bin/activate    # Windows: .venv\Scripts\activate
pip install -e .                # зависимости из requirements.txt
cp .env.example .env            # LLM_MODE=replay работает без ключей (ответы из data/llm_cache)
pytest -q                       # 32 офлайн-теста (заглушка LLM)
jupyter notebook notebooks/     # 01 - база и сравнение поиска, 02 - три кейса
python -m resident.pipeline     # то же в консоли
```

- **Новый прогон:** `LLM_MODE=live`, `GROQ_API_KEY` и `OPENROUTER_API_KEY` в `.env`. Модели - строка `провайдер:модель` в `LLM_MODEL` (planner, replanner, проверка находок) и `AUDITOR_MODEL`. Полный прогон без кэша - 25 минут (минутный лимит Groq), из кэша - секунды.
- **Пересборка базы:** `python -m resident.kb.fetch && python -m resident.kb.parse`.
- **Colab:** `!git clone <url>`, `%cd AI_Healthcare`, `!pip install -e .`; GPU не нужен, эмбеддинги уже в `data/kb/`.

## Ограничения

- Одна КР; нормы вне КР помечены (ОПП - KDIGO 2012, согласие - 323-ФЗ). Кинетика не откалибрована на реальных данных.
- LLM-аудитор почти всё значимое дублирует с правилами; из 9 его находок проверка отклонила 6, одна принятая спорная ([разбор](docs/details.md#разбор-результатов)).
- Без thinking Qwen назначает минимум, полноту держат проверки planner и правило R16. Replanner, несмотря на промпт, заменил эноксапарин на НФГ - ловит R13.
- Лимит Groq free - 200 тыс. токенов в день, примерно один полный прогон без кэша.
